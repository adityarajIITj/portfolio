# Aditya Raj — AI & Data Science Portfolio

An interactive portfolio for Aditya Raj, a B.Tech student in Applied AI and Data Science at IIT Jodhpur. The site brings together selected work, technical interests, and an evolving body of experiments in machine learning, security, and systems programming.

## Highlights

- **Interactive editorial experience** with smooth motion and responsive layouts
- **Projects** including Crystal Auth, a secure authentication framework, and an Indigenous LLM exploration built from transformer fundamentals
- **Technical focus** across Python, PyTorch, TensorFlow, NLP, LLMs, Pandas/NumPy, Linux, Git, and Docker
- **Portfolio story** covering the journey from early Python projects to practical AI and systems work
- **Contact and collaboration** links for research, open source, and ambitious builds

## Featured work

### Crystal Auth System

A production-oriented authentication framework built with Python and cryptography. It explores multi-factor authentication, modern encryption practices, and secure session lifecycle management.

### Indigenous LLM

An in-progress, hands-on study of large language models: implementing transformer components from scratch to understand the architecture beneath modern NLP systems.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3456](http://localhost:3456) in your browser.

## Tech

The portfolio is served with Vite and uses GSAP and Lenis for animation and smooth scrolling. The page content is maintained in `portfolio-overrides.js` so the portfolio copy remains consistent after the page loads.
